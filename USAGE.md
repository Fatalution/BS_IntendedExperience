# Using Intended Experience

## Settings

Found in Mod Settings → Intended Experience.

- **Enabled:** turns the mod on or off. The same switch is in the song browser tab. While it's off, the other settings are hidden.

### Map Types

Pick GLS Maps, Modcharts or Chroma Maps at the top. The toggles below it belong to the picked type. A map that fits more than one type uses the most specific one: modchart, then Chroma, then GLS.

- **Enable All Effects:** switches Off / No Flickering to All Effects.
- **Use Map Environment:** turns off your environment override, so the map plays in the environment it was made for.
- **Set Effects Brightness to 100%:** resets BeatSaberPlus GameTweaker's brightness override. Requires BeatSaberPlus GameTweaker.
- **Use Intended Colors:** switches an All color override to Notes Only and turns on the map's SongCore environment colors. Maps that set both environment color pairs keep your override. Note and wall colors stay the same. Chroma maps color their own lights, so they don't have this toggle.

On 1.29.1 there's no Notes Only option, so any color override counts as All there. IE keeps your note and wall colors and uses the environment's light colors.

Chroma maps only count as Chroma maps when Chroma is installed.

### Replays and Multiplayer+

- **Apply to replays:** also changes settings for BeatLeader and ScoreSaber replays.
- **Apply in Multiplayer+:** in Multiplayer+ lobbies, applies the map's Settings Setter and IE's changes without asking. Requires BeatSaberPlus Multiplayer+.

### Menu

- **Tint Play button:** turns the Play button orange when IE will change something for the map.
- **Show tooltips:** shows hover hints on the Play and IE buttons.
- **Show changes in Settings Setter:** on maps without a Settings Setter, shows IE's changes in a matching window after pressing Play. Requires Heck.

### Excluded maps

The maps you excluded with the IE button. Remove one to let IE handle it again, or clear them all.

### Included ranked maps

Ranked maps you turned IE on for with the IE button while their type is turned off for ranked maps. Remove one to skip it again, or clear them all.

## In game

- **Orange Play button:** IE will change something for this map. Hover over it to see what.
- **IE button** (next to Play, on GLS maps, Chroma maps and modcharts): excludes the selected map, or brings it back.
- **Mod Settings → Intended Experience:** settings and excluded maps.
- **Song browser, left menu → Mods → Intended Experience:** the Enabled switch, the selected map's type (GLS, Modchart, Chroma or Legacy, and whether it's ranked) and the list of changes.

## Settings Setter

Heck's Settings Setter lets a map ask for settings before it starts. Anything a map's Settings Setter sets is left to it, and IE adds its own rows to the same window.

On maps without one, turn on "Show changes in Settings Setter" to get the same kind of window for IE's changes.

In Multiplayer+ lobbies there's no window, so the map's Settings Setter and IE's changes are applied without asking.
